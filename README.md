# Sistema de Gestión de Biblioteca Comunal

## Descripción del proyecto

El proyecto consiste en desarrollar un sistema web para una biblioteca comunal, que permita administrar los libros, socios y préstamos, así como controlar la disponibilidad de los libros y sus devoluciones.

Estudiante: Fabián Arias Valverde

## Herramientas utilizadas

TypeScript
Angular
Node.js

## Ejecución del proyecto

### Prototipo TypeScript

Ingresar a la carpeta prototipo-ts y ejecutar:

npm install
npm run build
npm start

### Proyecto Angular

Ingresar a la carpeta frontend y ejecutar:

npm install
npm start

El proyecto Angular se puede visualizar desde http://localhost:4200.
